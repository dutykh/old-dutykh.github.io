# old-dutykh.github.io: the archive of the blog of Denys Dutykh, 2014 to 2017

This repository is the archive of the Jekyll blog that Denys Dutykh, applied mathematician, kept from May 2014 to May 2017: 55 posts of research notes, announcements of preprints, and tools for hydrodynamics, wave propagation and scientific computing. The blog is no longer published from here, and its posts are moving to the blog of his website,

https://www.denys-dutykh.com/

## Contents

| Path | What it holds |
|------|---------------|
| `_posts/` | The 55 posts, one Markdown file each, named `YYYY-MM-DD-slug.md`: 17 from 2014, 19 from 2015, 11 from 2016 and 8 from 2017 |
| `public/pics/` | The pictures of the posts and of the About page |
| `public/css/`, `public/` | The style sheets and icons of the theme |
| `about.md` | The About page of that time |
| `index.html`, `atom.xml`, `404.html` | The home page with five posts per page, the Atom feed, and the page for unknown addresses |
| `_layouts/`, `_includes/`, `_config.yml` | The templates and settings of the Jekyll site, which published each post at an address of the form `/YYYY/MM/DD/slug/` |
| `CNAME` | The domain the blog was published under, `dutykh.github.io` |
